# SOE Mobile

Application mobile Flutter pour le projet SOE.

## Prerequis

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (>= 3.10)
- Dart SDK (inclus avec Flutter)
- Android Studio / Xcode (selon la plateforme cible)

## Installation

```bash
git clone git@github.com:kenzo2013/soe-mobile.git
cd soe-mobile
flutter pub get
```

## Lancer l'application

```bash
flutter run
```

## Build

```bash
# Android
flutter build apk

# iOS
flutter build ios
```

## Tests

```bash
flutter test
```

## Structure du projet

```
lib/
  main.dart          # Point d'entree de l'application
test/
  widget_test.dart   # Tests unitaires et widget
```
